# QDU Street Law Club

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Lucide

    npm install
    npm run dev      # http://localhost:3000
    npm run build

- `data/` — kontent (a'zolar, tadbirlar, maqolalar, testlar). UI'dan alohida; hammasi NAMUNAVIY.
- `lib/repository.ts` — yagona ma'lumotlar qatlami. Supabase'ga o'tishda faqat shu fayl o'zgaradi.
- `components/` — qayta ishlatiladigan komponentlar.
